# RealBeef Africa – WordPress demo

A demo of the RealBeef Africa shop (100% grass-fed beef tallow, Nairobi) that runs entirely in the browser with WordPress Playground. Built like our Aura Glow site: a block theme on Twenty Twenty-Five with the products as WooCommerce products and a WhatsApp cart.

- Shop: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/realbeef-demo/main/blueprint.json
- Admin (products, prices, photos): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/realbeef-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so changes are not kept.
